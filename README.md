# Física visual

Un laboratorio abierto con visualizaciones interactivas de mecánica clásica,
ondas, termodinámica, mecánica cuántica y mecánica estadística.

**Abrir el sitio:** https://dgarciaaa.github.io/fisica-visual/

Este repositorio contiene los archivos públicos del sitio generado. El acceso
es gratuito y no requiere registro. Las bibliotecas integradas conservan sus
avisos de licencia dentro de cada visualización.
