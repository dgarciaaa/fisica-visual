Tres niveles de energía

Enunciado · 01 / 03

Sistema de partículas con tres niveles de energía.

Considere un sistema de NN partículas clásicas, no interactuantes, en contacto con un reservorio térmico a temperatura TT. Cada partícula puede tener una de las tres energías

ϵ0=0,ϵ1=ϵ,ϵ2=3ϵ,\epsilon_0=0, \qquad \epsilon_1=\epsilon, \qquad \epsilon_2=3\epsilon,

con ϵ>0\epsilon>0.

  1. (a)Obtenga la función de partición canónica del sistema.
  2. (b)Calcule la energía interna por partícula u(T)u(T).
  3. (c)Analice los límites T→0T\to 0 y T→∞T\to\infty de u(T)u(T).
  4. (d)Obtenga la entropía por partícula s(T)s(T).
  5. (e)Determine el calor específico por partícula y discuta su comportamiento cualitativo.
Fuente: Silvio R. A. Salinas, Introduction to Statistical Physics, problema 5.3.

(a) Función de partición

Para una partícula, la función de partición es

Z1=∑re−βϵr.Z_1 = \sum_r e^{-\beta\epsilon_r}.

Como los niveles disponibles son

0,ϵ,3ϵ,0,\qquad \epsilon,\qquad 3\epsilon,

tenemos

Z1=e−β(0)+e−βϵ+e−3βϵ.Z_1 = e^{-\beta(0)} + e^{-\beta\epsilon} + e^{-3\beta\epsilon}.

Por tanto,

Z1=1+e−βϵ+e−3βϵ.\boxed{ Z_1 = 1+e^{-\beta\epsilon}+e^{-3\beta\epsilon}. }

Como las partículas son independientes,

Z=Z1N=(1+e−βϵ+e−3βϵ)N.\boxed{ Z=Z_1^N = \left( 1+e^{-\beta\epsilon}+e^{-3\beta\epsilon} \right)^N. }

(b) Energía interna por partícula

La energía interna total es

U=−∂∂βln⁡Z.U=-\frac{\partial}{\partial\beta}\ln Z.

Como

ln⁡Z=Nln⁡Z1,\ln Z=N\ln Z_1,

la energía interna por partícula es

u=UN=−∂∂βln⁡Z1.u=\frac{U}{N} = -\frac{\partial}{\partial\beta}\ln Z_1.

Ahora,

Z1=1+e−βϵ+e−3βϵ.Z_1=1+e^{-\beta\epsilon}+e^{-3\beta\epsilon}.

Entonces

∂Z1∂β=−ϵe−βϵ−3ϵe−3βϵ.\frac{\partial Z_1}{\partial\beta} = -\epsilon e^{-\beta\epsilon} - 3\epsilon e^{-3\beta\epsilon}.

Por tanto,

u=−1Z1∂Z1∂β=ϵe−βϵ+3ϵe−3βϵ1+e−βϵ+e−3βϵ.u = -\frac{1}{Z_1} \frac{\partial Z_1}{\partial\beta} = \frac{ \epsilon e^{-\beta\epsilon} + 3\epsilon e^{-3\beta\epsilon} }{ 1+e^{-\beta\epsilon}+e^{-3\beta\epsilon} }.

Así,

u(T)=ϵe−βϵ+3e−3βϵ1+e−βϵ+e−3βϵ.\boxed{ u(T) = \epsilon \frac{ e^{-\beta\epsilon} + 3e^{-3\beta\epsilon} }{ 1+e^{-\beta\epsilon}+e^{-3\beta\epsilon} }. }

(c) Límites de temperatura

Para T→0T\to 0, se tiene β→∞\beta\to\infty. Entonces

e−βϵ→0,e−3βϵ→0.e^{-\beta\epsilon}\to 0, \qquad e^{-3\beta\epsilon}\to 0.

Luego,

u(T→0)→0.\boxed{ u(T\to 0)\to 0. }

Esto corresponde a que todas las partículas ocupan el nivel fundamental de energía cero.

Para T→∞T\to\infty, se tiene β→0\beta\to 0. Entonces

e−βϵ→1,e−3βϵ→1.e^{-\beta\epsilon}\to 1, \qquad e^{-3\beta\epsilon}\to 1.

Así,

u(T→∞)=ϵ1+31+1+1=4ϵ3.u(T\to\infty) = \epsilon \frac{1+3}{1+1+1} = \frac{4\epsilon}{3}.

Por tanto,

u(T→∞)→4ϵ3.\boxed{ u(T\to\infty)\to \frac{4\epsilon}{3}. }

A temperatura alta, los tres niveles se ocupan con igual probabilidad, por eso la energía media es

0+ϵ+3ϵ3=4ϵ3.\frac{0+\epsilon+3\epsilon}{3} = \frac{4\epsilon}{3}.

(d) Entropía por partícula

La energía libre por partícula es

f=−1βln⁡Z1=−kBTln⁡Z1.f=-\frac{1}{\beta}\ln Z_1=-k_BT\ln Z_1.

La entropía por partícula puede escribirse como

s=u−fT.s=\frac{u-f}{T}.

Por tanto,

s=uT+kBln⁡Z1.s = \frac{u}{T} + k_B\ln Z_1.

Como β=1/(kBT)\beta=1/(k_BT),

uT=kBβu.\frac{u}{T}=k_B\beta u.

Luego,

s(T)=kBln⁡(1+e−βϵ+e−3βϵ)+kBβϵe−βϵ+3e−3βϵ1+e−βϵ+e−3βϵ.\boxed{ s(T) = k_B\ln\left( 1+e^{-\beta\epsilon}+e^{-3\beta\epsilon} \right) + k_B\beta \epsilon \frac{ e^{-\beta\epsilon} + 3e^{-3\beta\epsilon} }{ 1+e^{-\beta\epsilon}+e^{-3\beta\epsilon} }. }

En los límites,

T→0:Z1→1,u→0,T\to 0: \qquad Z_1\to 1, \qquad u\to 0,

por lo que

s(T→0)→0.\boxed{ s(T\to 0)\to 0. }

Para T→∞T\to\infty,

Z1→3,βu→0,Z_1\to 3, \qquad \beta u\to 0,

y entonces

s(T→∞)→kBln⁡3.\boxed{ s(T\to\infty)\to k_B\ln 3. }

(e) Calor específico

El calor específico por partícula es

c=∂u∂T.c = \frac{\partial u}{\partial T}.

En el ensamble canónico también se puede escribir como

c=1kBT2(⟨ϵ2⟩−⟨ϵ⟩2).c = \frac{1}{k_BT^2} \left( \langle \epsilon^2\rangle - \langle \epsilon\rangle^2 \right).

Para una partícula,

⟨ϵ⟩=u,\langle \epsilon\rangle=u,

⟨ϵ2⟩=02e0+ϵ2e−βϵ+(3ϵ)2e−3βϵZ1.\langle \epsilon^2\rangle = \frac{ 0^2e^{0} + \epsilon^2e^{-\beta\epsilon} + (3\epsilon)^2e^{-3\beta\epsilon} }{ Z_1 }.

Entonces

⟨ϵ2⟩=ϵ2e−βϵ+9e−3βϵ1+e−βϵ+e−3βϵ.\langle \epsilon^2\rangle = \epsilon^2 \frac{ e^{-\beta\epsilon} + 9e^{-3\beta\epsilon} }{ 1+e^{-\beta\epsilon}+e^{-3\beta\epsilon} }.

Por tanto,

c(T)=kB(βϵ)2[e−βϵ+9e−3βϵ1+e−βϵ+e−3βϵ−(e−βϵ+3e−3βϵ1+e−βϵ+e−3βϵ)2].\boxed{ c(T) = k_B(\beta\epsilon)^2 \left[ \frac{ e^{-\beta\epsilon} + 9e^{-3\beta\epsilon} }{ 1+e^{-\beta\epsilon}+e^{-3\beta\epsilon} } - \left( \frac{ e^{-\beta\epsilon} + 3e^{-3\beta\epsilon} }{ 1+e^{-\beta\epsilon}+e^{-3\beta\epsilon} } \right)^2 \right]. }

En el límite T→0T\to 0, las partículas permanecen congeladas en el estado fundamental y las fluctuaciones de energía desaparecen:

c(T→0)→0.\boxed{ c(T\to 0)\to 0. }

En el límite T→∞T\to\infty, los tres niveles se ocupan casi por igual, pero el factor β2\beta^2 hace que

c(T→∞)→0.\boxed{ c(T\to\infty)\to 0. }

Por lo tanto, c(T)c(T) presenta un máximo intermedio, asociado a la escala térmica

kBT∼ϵ.k_BT\sim \epsilon.

Qué representa este ensamble

Los niveles son 0, ε y 3ε. Las plataformas representan energía; sus alturas conservan la razón 0:1:3. Las esferas son las N partículas del modelo; su altura indica el nivel que ocupa cada una. Azul, verde y lavanda identifican respectivamente los tres niveles.

θ = kBT/ε es la temperatura reducida y βε = 1/θ. Las energías permanecen fijas al variar T. Los valores u/ε, s/kB y c/kB son por partícula; U = Nu, S = Ns y C = Nc. ε fija la escala de energía.

Seguimos Z = Z₁ᴺ de la solución: N grados de libertad independientes e identificables.

Una muestra asigna a cada partícula un nivel con probabilidades pᵣ = exp(−βεᵣ)/Z₁. Las cantidades nᵣ cuentan las esferas en cada nivel y fluctúan entre muestras, junto con la energía de la configuración. La línea discontinua de u corresponde al promedio exacto del ensamble.

Muestrear genera una configuración independiente cada 1,2 segundos de reproducción; Paso genera exactamente una. El intervalo define el ritmo de presentación. Cambiar θ o N inicia un nuevo conjunto de muestras; navegar o girar la cámara conserva los parámetros.

s/kB = −Σpᵣ ln pᵣ mide la incertidumbre de la energía de una partícula. c/kB = Var(E/ε)/θ² mide cuánto responde u a T. En Calor específico, la marca vertical σE muestra la desviación estándar de la energía de una partícula. A temperatura muy alta la varianza sigue siendo finita, aunque c tiende a cero.

Las gráficas muestran el resultado seleccionado frente a θ en escala logarítmica; en Partición, las tres curvas representan p₀, p₁ y p₂ con los colores de los niveles. Los puntos señalan los valores de la temperatura elegida. Las líneas horizontales discontinuas indican los límites 4/3 para u/ε y ln 3 para s/kB. T → 0 y T → ∞ se calculan como límites exactos; el deslizador recorre 0,03 ≤ θ ≤ 60.

Arrastra para girar, rueda o gesto para acercar. Flechas y +/− ofrecen controles de cámara por teclado. Reiniciar vuelve a θ = 1, N = 60 y la cámara inicial, conservando el resultado seleccionado.

La escena 3D requiere conexión para Three.js y WebGL 2. Las ecuaciones, cálculos, controles y vista 2D funcionan sin conexión.
